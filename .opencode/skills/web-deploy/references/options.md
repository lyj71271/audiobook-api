## 선택 기준

- **카드 없이 → Render Free.** GitHub 연결 후 10분이면 배포. 750시간이면 24시간 1대 운영 가능.
- **슬립 대책:** 15분 유휴 시 슬립 → UptimeRobot 등 무료 핑(10분 간격 /health)으로 유지. 장문 변환 중 폴링 자체가 트래픽이라 안 잠듦.
- **장문 한계:** 프록시 타임아웃 대비 전부 잡+폴링 (이미 적용됨). 그래도 1시간+ 작업은 유료/자가 권장.
- **폰이 집 밖에서도 쓴다 → Render URL(https) 입력.** 클리어텍스트 문제 없음.

## 비용 주의

- edge-tts는 MS 무료 엔드포인트라 별도 키·비용 없음. 과도 호출 시 429 → `max_concurrency` 하향.
