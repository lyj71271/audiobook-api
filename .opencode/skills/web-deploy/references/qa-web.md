# QA Web (배포 완료 조건)

## 배포

- [ ] `docker build` 성공, 이미지 1GB 이하
- [ ] 로컬 `docker run`에서 `/health` 200
- [ ] 호스트 배포 후 `https://<도메인>/health` 200
- [ ] 환경변수에 비밀값 없음 (이미지·코드 스캔)

## 기능 (운영 URL 기준)

- [ ] 단문 합성 → 다운로드 → 재생 (수 초)
- [ ] 장문 변환(10분짜리) → 중간에 안 죽고 `done`
- [ ] 한글 파일명 다운로드 정상
- [ ] 동시 2건 변환 시 둘 다 완료 (슬립형은 1건만 보장)

## 앱 연동

- [ ] 모바일 설정에 `https://<도메인>` 입력 → 연결됨
- [ ] 집 Wi-Fi 밖(모바일 데이터)에서도 합성·다운로드 성공
- [ ] CORS 에러 없음 (브라우저 콘솔·앱 로그 확인)

## 운영

- [ ] 재배포 후에도 변환 기능 정상 (out/ 휘발 인지)
- [ ] 무료枠 초과 알람 설정 (결제수단 등록 시)
- [ ] 장애 시 `docker logs` / 호스트 로그 확인 경로 확보
