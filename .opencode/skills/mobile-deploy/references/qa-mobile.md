# QA Mobile (실기기 완료 조건)

## 설치

- [ ] `flutter build apk --release` 성공, `app-release.apk` 생성
- [ ] 실기기 설치 성공 (USB `adb install` 또는 파일 전송)
- [ ] 앱 이름 `오디오북`, 한글 UI 확인

## 접속

- [ ] 설정에서 `http://<PC-IP>:8000` 입력 → 연결 확인 표시
- [ ] 같은 Wi-Fi 아닐 때 명확한 오류 안내
- [ ] 서버 꺼져 있을 때 무한 로딩이 아닌 오류 메시지

## 기능 (실기기)

- [ ] 단문 합성 → 다운로드 → 기기에서 재생 (스피커 출력 확인)
- [ ] 장문 변환 → 진행률 → 완료 → 다운로드 → 재생
- [ ] 한글 제목 파일 다운로드 정상 (깨짐 없음)
- [ ] 대용량(50MB+) 다운로드 중 메모리 크래시 없음
- [ ] 이어듣기: 앱 재시작 후 저장 위치부터 재생
- [ ] 배속 0.8x~2.0x, 10초 점프 동작

## 권한·보안

- [ ] 최초 실행 시 불필요한 권한 요구 없음 (저장소는 앱 전용 폴더)
- [ ] 릴리스에서 LAN http 통신 정상 (클리어텍스트 설정 확인)
- [ ] 방화벽 규칙 없이 외부망 노출 없음 (LAN 한정)
