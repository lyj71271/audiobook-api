# QA Checklist

완료 선언 전 모두 체크. 실패 항목은 수정 후 재검증.

## 기능

- [ ] 빈 입력 → 명확한 에러, 크래시 없음
- [ ] 1글자 입력 → 정상 합성 또는 최소길이 안내
- [ ] 10만자 장문 → 청킹+큐+재개(manifest) 동작
- [ ] txt/pdf/epub/docx 중 선언 범위 모두 변환 성공
- [ ] 스캔본 PDF → "OCR 필요" 안내, 빈 오디오 생성 안 함
- [ ] 특수문자/이모지/URL 혼합 → 발음 깨짐 없이 클리닝

## TTS/오디오

- [ ] edge-tts 순차 합성, 429 없음
- [ ] 네트워크 차단 시 piper 자동 폴백
- [ ] 0바이트/1초 미만 wav 검출 + 재시도
- [ ] 챕터 경계 무음(0.8s), 문단 무음(0.3s) 청취 확인
- [ ] 최종 mp3 메타데이터(제목/저자) 표시 확인
- [ ] ffmpeg 미설치 시 설치 안내 메시지 출력

## 크로스플랫폼

- [ ] 타깃 2종 이상(예: Windows + Android)에서 저장+재생 확인
- [ ] 모바일 백그라운드/잠금화면 재생 지속
- [ ] 이어듣기 위치 저장/복원
- [ ] 배속 0.8x~2.0x 재생 확인

## 코드

- [ ] `core/tts/audio`가 UI import 없음
- [ ] API 키 하드코딩 없음
- [ ] `pytest` 통과
- [ ] 중간 wav + manifest로 중단 후 재개 가능
